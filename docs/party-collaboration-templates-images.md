# 两人／三人协作、课时模板与图片素材

## 教师操作

### 创建小组与补入第三人

在“协作课堂”创建小教室，选择自己授权班级内的 2～3 名学生。同班可以同时有两人组和三人组。学生不能重复加入其他 PAIA 小组。

已有两人组可通过卡片上的“添加成员”补入一名同班学生。补人保留原房间、聊天、HTML/CSS、任务阶段和当前 Driver，并记录成员变化时间。在线学生会收到成员和角色更新。

每组只有一名 Driver。两人组按 A → B → A 交棒，三人组按 A → B → C → A 交棒；其余成员均为 Navigator。教师通过“进入观察”只读查看讨论、代码和网页预览，观察连接不占学生名额。

### 编写和发布本课编程练习

1. 在自己的课程和班级下选择“课时管理”，进入对应课时。
2. 切换到“本课编程练习”，分别编辑 HTML 和 CSS，点击“预览练习”检查结果。例如 HTML 填入 `<p>请修改这段文字</p>`。
3. 点击“保存并发布练习”，发布会先保存当前课时配置；也可先“保存课时”，再点击顶部“发布课时”，将文字任务、附件和本课编程练习一起发布。仅保存草稿不会更新学生端。
4. 学生端会显示模板所属课时，由当前 Driver 主动载入；教师发布或重新发布不会替换学生正在编辑的作品。

当前小教室以学生班级匹配模板，提供该班级通过上述任一入口最近一次发布的有效编程模板。学生端收到发布通知、重新连接或切回窗口时刷新模板信息，页面可见时每 15 秒检查一次。上不同课时前请发布对应课时，并让学生核对显示的课时名称。当前房间没有独立的课程绑定或模板选择列表。

### 设置学生填写区

在“本课编程练习”中，先写好完整代码，再选中希望学生修改的部分，点击“设为填写区”。没有选中文字时，会在光标处插入 `____` 并设为填写区。HTML、CSS 均支持多个填写区，标记后自动切换为“代码填空”。点击填写区编号后的 × 只移除标记，不删除代码。

“代码填空”发布后，学生只能修改高亮部分，可以清空后重新填写，其他代码由编辑器和服务器共同保护。没有设置填写区时不能发布填空练习。“自由编程”允许修改全部代码，旧模板默认沿用自由编程。学生端“下一个填写区”可依次定位空位；此功能不包含自动判分。

例如 `<img src="____" alt="示例">`，只选中四条下划线设为填写区，学生即可在该处选择图片；`img` 标签和其他属性保持锁定。填写区随协作文档保存，刷新、切换长期任务后返回仍然有效。受保护练习只允许恢复同一模板版本的受保护历史，不能借旧版本解锁教师代码。

## 学生操作

### 长期任务与本课练习

右侧顶部提供“长期任务”和“本课练习”两个区域。原房间已有的代码、历史版本和进度沿用为长期任务，不自动移动或清空已有内容。

- **长期任务**：持续完善小组作品。HTML/CSS 自动保存到服务器，也可由 Driver 点击“保存进度”，确认状态为“已保存”后结束学习。重新进入同一小教室可继续。
- **本课练习**：载入老师发布的课时模板，修改代码、预览并学习知识点。练习内容和长期任务各自保存，载入模板只替换本课练习。
- 由当前 Driver 带全组切换区域，Navigator 与教师观察页实时跟随。切换前会先保存正在编辑的内容；同步未完成或保存失败时保留原区域并提示重试。
- 两个区域各自保留 HTML/CSS、历史版本、任务阶段、模板载入记录与预览记录；小组成员及 Driver/Navigator 角色共用。过程事件标记所属区域，群聊 AI 继续读取当前活动区域的代码。

当前提供一份长期任务和一份本课练习，不是逐课时练习档案库。载入下一课模板前，当前练习会留入本课练习的历史版本；需要长期留存某课成品时，可下载 HTML。历史版本仍按各区域最近 20 个版本保留。

### 载入与恢复

Driver 先切换到“本课练习”，再点击“载入本课模板”，确认后系统先保存练习版本，再同步替换全组练习区的 HTML/CSS。Navigator 可以查看模板信息，不能载入或编辑，页面会显示由哪位 Driver 载入。模板未发布时可继续编辑练习区的初始代码。

学生确认时若代码或模板版本已变化，系统拒绝覆盖并提示重新核对。重复的同一载入请求只执行一次；旧连接不能把载入前的内容写回新作品。

房间创建者可从当前区域的“历史代码版本”选择版本并点击“恢复版本”。恢复前先保存当前作品，且只影响当前区域，权限沿用原有房主规则。历史版本数量仍受现有工作区保留上限约束。

### 选择图片

1. 当前 Driver 在 HTML 中写入 `<img src="" alt="图片说明">`。
2. 将光标放在 `src` 的值内，点击“为 src 选择图片”。
3. 选择本机 PNG、JPG、GIF 或 WebP 图片，单张不超过 6 MB。
4. 上传成功后自动填入 `assets/<资源标识>.<扩展名>`，其他属性和周围代码保留原样。
5. 点击“预览”。其他组员和教师观察页可查看同一张图片。

如果老师启用了“代码填空”，`src` 的值必须属于填写区才允许插入图片。学生不需要自己复制电脑文件路径，也不要填写 `C:\\...` 或 `/Users/...`；选择图片后平台会自动写入共享资源路径。

上传失败、上传期间交棒、载入其他作品或修改目标 `src` 时，系统保留代码并提示重新选择。源代码中的资源标识可以持久保存；图片预览由平台按房间权限读取，不依赖原电脑路径或短期签名链接。

素材读取复用现有 OSS 配置，没有新增环境变量。图片归属于上传的小组；把素材标识复制到另一个小组不会授予访问权限。当前功能面向平台内共享预览，复制原始代码到平台外运行时需要另行携带图片素材。

手机端使用顶部“讨论／编程”切换工作区，通过“小组与任务”打开侧栏。切换保留协作连接和代码状态。

教师课时管理的列表可通过“收起列表／展开列表”切换，收起后编辑区占用释放的宽度。桌面布局按可用宽度和高度适配，1280×800、1366×768、1440×900、1920×1080 已进行展开与收起检查；低高度桌面进一步压缩练习工具栏间距。

## 兼容与发布

### 数据和协议

- 旧两人房间仍可读取：保留 `navigatorUserId`，新增 `navigatorUserIds` 表达全部 Navigator。首次读取协作角色时按实际成员补齐数组，保留当前 Driver 和轮换次数。
- 新增成员历史 `membershipHistory`；补人前后的事件按实际成员时间段进入纵向记忆，不把旧搭档贡献归给后来加入的学生。
- 课时草稿包含 `programmingTemplate`；“发布课时”的编程内容随课时发布快照保存，“保存并发布练习”的内容保存于 `party_lesson_templates`。学生模板接口比较两种正式发布的时间，读取最新内容，不读取未发布草稿。
- 图片元数据保存于 `party_coding_images`，实际文件继续存于既有 OSS。
- 协作工作区新增 `activeWorkspace`（旧数据默认 `project`）、`storedWorkspaces` 与 `savedAt`。当前区域仍保留在顶层供既有 AI 和观察接口读取，另一份文档独立存入同一房间记录；不需要迁移或清空旧作品。切换、模板载入和恢复会递增代数，旧连接和旧 HTTP 操作不能写入切换后的区域。
- 协作工作区新增 `documentEpoch` 和 `loadedTemplate`，用于作品替换后的旧消息识别和载入追踪。旧房间缺省代数为 0。
- 前后端与群聊 AI worker 应一起更新，更新后让在线学生刷新页面，避免旧客户端继续使用两人角色和旧同步协议。
- 预览仍在禁用脚本的 iframe 中运行；没有开放 `allow-scripts`。API 与素材读取遵循 `EDUCHAT_BASE_PATH`。

### 已保存的群聊 AI 默认提示词

代码默认配置、普通群聊 AI 的编程上下文和主动参与度分析已支持 2～3 人。教师自定义提示词保留原样；若其文字明确限定“两位”，请由教师按教学意图修改。

检查 MongoDB 中是否保存了可识别的旧默认提示词：

```sh
node scripts/backfill-party-group-prompts.mjs
```

默认只检查并输出是否命中，不修改数据。确认输出 `recognizedStoredDefault: true` 后，如需将该旧默认内容更新到数据库，执行：

```sh
node scripts/backfill-party-group-prompts.mjs --apply
```

脚本仅匹配已有已知默认值，并在写入时复核原值；不会覆盖教师自定义内容，也不会输出提示词或数据库凭据。实际运行配置读取也会识别并转换这些旧默认值。

### 发布核验

发布前核对已有小组、教师自定义提示词和 OSS 可用性。发布后完成两人／三人轮换、模板载入与版本恢复、同组与教师图片预览，并确认学生刷新后的权限状态。参与度分析仍由原有开关控制，未启用时不会因本次升级自动开启。
